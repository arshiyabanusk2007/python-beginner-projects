# Python Beginner Projects

A collection of beginner-level Python programs developed while learning programming fundamentals and problem-solving.

## Projects

### 1. Simple Calculator

A basic calculator that performs addition, subtraction, multiplication, and division.

**File:** `calculator.py`

### 2. Word Counter

A simple program that counts the number of words in a sentence using Python string operations.

**File:** `word_counter.py`

### 3. Student Grade Calculator

A program that accepts student marks, calculates the average, and displays the corresponding grade.

**File:** `student_grade_calculator.py`

## Skills Practiced

* Python programming
* Variables and data types
* User input
* Arithmetic operations
* Conditional statements
* String handling
* Basic problem solving
